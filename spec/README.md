# spec: the plan, before the code

RightFit is built spec first: a feature is written down here before it is coded.

| File | What it is |
|---|---|
| `constitution/mission.md` | the problem, the scope and the principles |
| `constitution/roadmap.md` | the milestones, the features and who does what |
| `constitution/tech_stack.md` | the tools, the architecture and the folders |
| `features/maf_checker.md` | the MAF review, in detail |
| `features/revit_fit_check.md` | the fit check in Revit, in detail |

When another file disagrees with these, these win.
